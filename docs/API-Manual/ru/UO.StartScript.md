# UO.StartScript

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: ru -->

Загружает файл Basic и запрашивает запуск его открытой процедуры Sub Main.

## Точный синтаксис

```text
UO.StartScript(ScriptPath:Any) -> Integer
```

## Параметры

- `ScriptPath` — Обязательный ScriptPath — строка. Относительный путь начинается в папке AutoLoad этого клиента; абсолютный путь допустим. Путь с пробелами заключайте в кавычки. Нужен файл поддерживаемого Basic с открытой Sub Main без обязательных аргументов.

## Возвращает

Integer: количество активных запусков после принятого запуска; 65535 (0xFFFF) = ошибка запуска. Это не индекс нового скрипта, не Boolean и не результат завершения.

## Поведение

- Учитываются выполняющиеся и приостановленные запуски; завершённые и получившие запрос отмены исключаются. Работающий скрипт обычно учитывает и себя. Просто загруженная вкладка IDE запуском не считается.
- Индексы — текущие позиции в порядке запуска. Запуск/остановка скриптов могут сдвинуть позиции. Разные вызовы не образуют общий атомарный снимок; перед последующей командой управления перечитайте список.
- Закрытие Basic IDE не удаляет активные запуски. Команды относятся к этому клиенту, а не к другим клиентам или процессам Windows.
- GetScriptsList даёт индексы, GetScriptsCount — количество, GetScriptState — код из трёх состояний. Не подменяйте одно другим и не считайте любой ненулевой результат значением true.
- Перед примерами отдельно создайте указанные файлы Worker.bas. Ошибочный/недоступный путь, неподходящая Main, отключённый Basic или запрет параллельного запуска дают отказ. Если прежний запуск ещё останавливается, возможен отложенный повтор; принятие запуска не означает завершения. Короткий скрипт может закончить работу ещё до чтения возвращённого количества.

### Внутренние функции: от вызова до результата

### Полная вспомогательная функция

```vb
# Полная вспомогательная функция
#
# Загружает файл Basic и запрашивает запуск его открытой процедуры Sub Main.
#
# Integer: количество активных запусков после принятого запуска; 65535 (0xFFFF) = ошибка

SUB Main()
    # Под Main приведена функция целиком. Её параметры и результат объясняются отдельно от

    # Integer: количество активных запусков после принятого запуска; 65535 (0xFFFF) = ошибка

        UO.Print("launch accepted")
    Else
        UO.Print("check file, Main and execution settings")
    End If

Function TryStartBasic(fileName) As Boolean
    Dim count=UO.StartScript(fileName)
    Return count<>65535
End Function
```
