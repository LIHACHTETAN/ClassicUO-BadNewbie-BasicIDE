# UO.GetScriptsList

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: ru -->

Возвращает текущие числовые индексы скриптов.

## Точный синтаксис

```text
UO.GetScriptsList() -> Array
```

## Параметры

Параметров нет.

## Возвращает

Array из Integer: индексы 0..N-1 либо пустой массив. Элементы — числа, а не имена и не текстовые записи.

## Поведение

- Учитываются выполняющиеся и приостановленные запуски; завершённые и получившие запрос отмены исключаются. Работающий скрипт обычно учитывает и себя. Просто загруженная вкладка IDE запуском не считается.
- Индексы — текущие позиции в порядке запуска. Запуск/остановка скриптов могут сдвинуть позиции. Разные вызовы не образуют общий атомарный снимок; перед последующей командой управления перечитайте список.
- Закрытие Basic IDE не удаляет активные запуски. Команды относятся к этому клиенту, а не к другим клиентам или процессам Windows.
- GetScriptsList даёт индексы, GetScriptsCount — количество, GetScriptState — код из трёх состояний. Не подменяйте одно другим и не считайте любой ненулевой результат значением true.
- Аргументов нет. Каждое число передавайте в соответствующий getter имени, пути или состояния. Полученный массив — отдельный снимок; его изменение не управляет скриптами.

### Полная вспомогательная функция

```vb
# Полная вспомогательная функция
#
# Возвращает текущие числовые индексы скриптов.
#
# Array из Integer: индексы 0..N-1 либо пустой массив. Элементы — числа, а не имена и не
# текстовые записи.

SUB Main()
    # Под Main приведена функция целиком. Её параметры и результат объясняются отдельно от
    # API-команды, которую она вызывает.
    # FindNamedScript перебирает текущие индексы и возвращает первое точное совпадение отображаемого
    # имени либо -1. Имена могут повторяться, индексы могут позже сдвинуться.
    # Array из Integer: индексы 0..N-1 либо пустой массив. Элементы — числа, а не имена и не
    # текстовые записи.

    Dim index=FindNamedScript("Mining")
    If index>=0 Then
        UO.Print(CStr(index))
    Else
        UO.Print("Name not found")
    End If
END SUB

Function FindNamedScript(wanted) As Integer
    Dim indices=UO.GetScriptsList()
    For Each index In indices
        If UO.GetScriptName(index)=wanted Then
            Return index
        End If
    Next
    Return -1
End Function
```

**Разбор параметров и выполнения:**

- Под Main приведена функция целиком. Её параметры и результат объясняются отдельно от API-команды, которую она вызывает.
- FindNamedScript перебирает текущие индексы и возвращает первое точное совпадение отображаемого имени либо -1. Имена могут повторяться, индексы могут позже сдвинуться.
- Array из Integer: индексы 0..N-1 либо пустой массив. Элементы — числа, а не имена и не текстовые записи.
