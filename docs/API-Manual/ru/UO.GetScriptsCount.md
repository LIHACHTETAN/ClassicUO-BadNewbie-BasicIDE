# UO.GetScriptsCount

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: ru -->

Считает активные запуски в этом клиенте.

## Точный синтаксис

```text
UO.GetScriptsCount() -> Integer
```

## Параметры

Параметров нет.

## Возвращает

Integer >= 0: число активных запусков, включая приостановленные. Это количество, а не Boolean и не индекс скрипта.

## Поведение

- Учитываются выполняющиеся и приостановленные запуски; завершённые и получившие запрос отмены исключаются. Работающий скрипт обычно учитывает и себя. Просто загруженная вкладка IDE запуском не считается.
- Индексы — текущие позиции в порядке запуска. Запуск/остановка скриптов могут сдвинуть позиции. Разные вызовы не образуют общий атомарный снимок; перед последующей командой управления перечитайте список.
- Закрытие Basic IDE не удаляет активные запуски. Команды относятся к этому клиенту, а не к другим клиентам или процессам Windows.
- GetScriptsList даёт индексы, GetScriptsCount — количество, GetScriptState — код из трёх состояний. Не подменяйте одно другим и не считайте любой ненулевой результат значением true.
- Аргументов нет. Подсчёт не сортирует список и не меняет состояние запусков.

### Полная вспомогательная функция

```vb
# Полная вспомогательная функция
#
# Считает активные запуски в этом клиенте.
#
# Integer >= 0: число активных запусков, включая приостановленные. Это количество, а не Boolean
# и не индекс скрипта.

SUB Main()
    # Под Main приведена функция целиком. Её параметры и результат объясняются отдельно от
    # API-команды, которую она вызывает.
    # HasOtherScripts сравнивает количество с 1: вызывающий скрипт обычно занимает одну запись. В
    # отличие от GetScriptsCount, вспомогательная функция возвращает true/false.
    # Integer >= 0: число активных запусков, включая приостановленные. Это количество, а не Boolean
    # и не индекс скрипта.

    If HasOtherScripts() Then
        UO.Print("Other executions are active")
    Else
        UO.Print("No other active executions")
    End If
END SUB

Function HasOtherScripts() As Boolean
    Dim count=UO.GetScriptsCount()
    Return count > 1
End Function
```

- Под Main приведена функция целиком. Её параметры и результат объясняются отдельно от API-команды, которую она вызывает.
- HasOtherScripts сравнивает количество с 1: вызывающий скрипт обычно занимает одну запись. В отличие от GetScriptsCount, вспомогательная функция возвращает true/false.
- Integer >= 0: число активных запусков, включая приостановленные. Это количество, а не Boolean и не индекс скрипта.
