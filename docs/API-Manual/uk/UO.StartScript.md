# UO.StartScript

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: uk -->

Завантажує файл Basic і запитує запуск його відкритої процедури Sub Main.

## Точний синтаксис

```text
UO.StartScript(ScriptPath:Any) -> Integer
```

## Параметри

- `ScriptPath` — Обов’язковий ScriptPath — рядок. Відносний шлях починається в папці AutoLoad цього клієнта; абсолютний дозволений. Шлях із пробілами беріть у лапки. Файл має містити підтримуваний Basic і відкриту Sub Main без обов’язкових аргументів.

## Повертає

Integer: кількість активних запусків після прийнятого запуску; 65535 (0xFFFF) = помилка запуску. Це не індекс нового скрипта, не Boolean і не результат завершення.

## Поведінка

- Враховуються виконувані й призупинені запуски; завершені та ті, що отримали скасування, виключаються. Скрипт зазвичай враховує себе. Просто завантажена вкладка IDE запуском не є.
- Індекси — поточні позиції в порядку запуску. Запуск/зупинка можуть їх зсунути. Окремі виклики не утворюють атомарний знімок; перед наступною командою керування перечитайте список.
- Закриття Basic IDE не видаляє активних запусків. Команди стосуються цього клієнта, а не інших клієнтів чи процесів Windows.
- GetScriptsList дає індекси, GetScriptsCount — кількість, GetScriptState — код із трьох станів. Не підміняйте ці значення й не вважайте будь-яке ненульове число значенням true.
- Перед прикладами окремо створіть зазначені файли Worker.bas. Хибний/недоступний шлях, непридатна Main, вимкнений Basic чи заборона паралельного запуску дають відмову. Якщо попередній запуск ще зупиняється, можливий відкладений повтор; прийняття запуску не означає завершення. Короткий скрипт може завершитися до читання поверненої кількості.

### Внутрішні функції: від виклику до результату

Нижче наведено справжні методи клієнта. Приклади Basic вище містять повні допоміжні функції; назви внутрішніх методів C# не є додатковими командами скрипта.

#### 1. ExecuteStealthCompatibility

Runtime викликає зареєстровану UO-команду й обгортає результат моста як Integer, String або Array.

Integer: кількість активних запусків після прийнятого запуску; 65535 (0xFFFF) = помилка запуску. Це не індекс нового скрипта, не Boolean і не результат завершення.

Код проєкту: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApiUO.cs`; функція `ExecuteStealthCompatibility`.

#### 2. StartScript

Міст звертається до менеджера запусків саме цього клієнта.

Перед прикладами окремо створіть зазначені файли Worker.bas. Хибний/недоступний шлях, непридатна Main, вимкнений Basic чи заборона паралельного запуску дають відмову. Якщо попередній запуск ще зупиняється, можливий відкладений повтор; прийняття запуску не означає завершення. Короткий скрипт може завершитися до читання поверненої кількості.

Код проєкту: `src/ClassicUO.Client/Game/Managers/ClassicUOInjectionApiBridge.cs`; функція `StartScript`.

#### 3. StartScript

`Path.GetFullPath -> File.ReadAllText -> DiscoverProcedures -> SelectFileEntryPoint -> RunProcedure -> GetScriptsCount`

Індекси — поточні позиції в порядку запуску. Запуск/зупинка можуть їх зсунути. Окремі виклики не утворюють атомарний знімок; перед наступною командою керування перечитайте список.

Код проєкту: `src/ClassicUO.Client/Game/Managers/YokoInjectionManager.cs`; функція `StartScript`.

### Повна допоміжна функція

```vb
# Повна допоміжна функція
#
# Завантажує файл Basic і запитує запуск його відкритої процедури Sub Main.
#
# Integer: кількість активних запусків після прийнятого запуску; 65535 (0xFFFF) = помилка

SUB Main()
    # Під Main наведено функцію повністю. Її параметри та результат пояснено окремо від API-команди,
    # яку вона викликає.

    # не перетворює кількість на індекс.
    # Integer: кількість активних запусків після прийнятого запуску; 65535 (0xFFFF) = помилка
    # запуску. Це не індекс нового скрипта, не Boolean і не результат завершення.

    If TryStartBasic("Scripts/Worker.bas") Then
        UO.Print("launch accepted")
    Else
        UO.Print("check file, Main and execution settings")
    End If
END SUB

Function TryStartBasic(fileName) As Boolean
    Dim count=UO.StartScript(fileName)
    Return count<>65535
End Function
```
