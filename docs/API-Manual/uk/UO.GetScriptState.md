# UO.GetScriptState

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: uk -->

Читає стан виконання за індексом.

## Точний синтаксис

```text
UO.GetScriptState(ScriptIndex:Any) -> Integer
```

## Параметри

- `ScriptIndex` — Обов’язковий ScriptIndex — цілий індекс від нуля зі свіжого GetScriptsList. Від’ємний або відсутній індекс дає описаний порожній/невідомий результат. Не передавайте serial предмета, ім’я процедури чи ID запуску IDE.

## Повертає

Integer — код стану: 0 = немає/невідомо, 1 = виконується, 2 = пауза. Це не Boolean: явно порівнюйте з 1 або 2.

## Поведінка

- Враховуються виконувані й призупинені запуски; завершені та ті, що отримали скасування, виключаються. Скрипт зазвичай враховує себе. Просто завантажена вкладка IDE запуском не є.
- Індекси — поточні позиції в порядку запуску. Запуск/зупинка можуть їх зсунути. Окремі виклики не утворюють атомарний знімок; перед наступною командою керування перечитайте список.
- Закриття Basic IDE не видаляє активних запусків. Команди стосуються цього клієнта, а не інших клієнтів чи процесів Windows.
- GetScriptsList дає індекси, GetScriptsCount — кількість, GetScriptState — код із трьох станів. Не підміняйте ці значення й не вважайте будь-яке ненульове число значенням true.
- Враховуються ручна/налагоджувальна пауза та налаштована пауза при від’єднанні. Стан 1 не гарантує, що скрипт саме зараз використовує процесор або отримує дані сервера.

### Внутрішні функції: від виклику до результату

Нижче наведено справжні методи клієнта. Приклади Basic вище містять повні допоміжні функції; назви внутрішніх методів C# не є додатковими командами скрипта.

#### 1. ExecuteStealthCompatibility

Runtime викликає зареєстровану UO-команду й обгортає результат моста як Integer, String або Array.

Integer — код стану: 0 = немає/невідомо, 1 = виконується, 2 = пауза. Це не Boolean: явно порівнюйте з 1 або 2.

Код проєкту: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApiUO.cs`; функція `ExecuteStealthCompatibility`.

#### 2. GetScriptState

Міст звертається до менеджера запусків саме цього клієнта.

Враховуються ручна/налагоджувальна пауза та налаштована пауза при від’єднанні. Стан 1 не гарантує, що скрипт саме зараз використовує процесор або отримує дані сервера.

Код проєкту: `src/ClassicUO.Client/Game/Managers/ClassicUOInjectionApiBridge.cs`; функція `GetScriptState`.

#### 3. GetScriptState

`script == null ? 0 : script.IsPaused ? 2 : 1`

Індекси — поточні позиції в порядку запуску. Запуск/зупинка можуть їх зсунути. Окремі виклики не утворюють атомарний знімок; перед наступною командою керування перечитайте список.

Код проєкту: `src/ClassicUO.Client/Game/Managers/YokoInjectionManager.cs`; функція `GetScriptState`.

Закриття Basic IDE не видаляє активних запусків. Команди стосуються цього клієнта, а не інших клієнтів чи процесів Windows.

### Використання в циклі чи умові

```vb
# Використання в циклі чи умові
#
# Читає стан виконання за індексом.
#
# Integer — код стану: 0 = немає/невідомо, 1 = виконується, 2 = пауза. Це не Boolean: явно
# порівнюйте з 1 або 2.

SUB Main()
    # Це окремий приклад спільного використання команд. Індекси масиву починаються з нуля;
    # перевіряйте довжину перед зверненням. Wait(250), де він використаний, чекає 250 мілісекунд.
    # Враховуються ручна/налагоджувальна пауза та налаштована пауза при від’єднанні. Стан 1 не
    # гарантує, що скрипт саме зараз використовує процесор або отримує дані сервера.
    # Integer — код стану: 0 = немає/невідомо, 1 = виконується, 2 = пауза. Це не Boolean: явно
    # порівнюйте з 1 або 2.
    # Обов’язковий ScriptIndex — цілий індекс від нуля зі свіжого GetScriptsList. Від’ємний або
    # відсутній індекс дає описаний порожній/невідомий результат. Не передавайте serial предмета,
    # ім’я процедури чи ID запуску IDE.

    Dim indices=UO.GetScriptsList()

    UO.Print(CStr(paused))
END SUB
```

```vb
# Читає стан виконання за індексом.

    # яку вона викликає.

    # порівнюйте з 1 або 2.

    If IsScriptActive(0)=True Then
        UO.Print("running or paused")
    Else

Function IsScriptActive(index) As Boolean
    Dim state=UO.GetScriptState(index)
    Return state=1 OrElse state=2
End Function
```
