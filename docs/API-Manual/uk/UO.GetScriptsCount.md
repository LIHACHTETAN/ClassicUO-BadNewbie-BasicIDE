# UO.GetScriptsCount

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: uk -->

Рахує активні запуски в цьому клієнті.

## Точний синтаксис

```text
UO.GetScriptsCount() -> Integer
```

## Параметри

Параметрів немає.

## Повертає

Integer >= 0: кількість активних запусків, включно з призупиненими. Це кількість, а не Boolean чи індекс.

## Поведінка

- Враховуються виконувані й призупинені запуски; завершені та ті, що отримали скасування, виключаються. Скрипт зазвичай враховує себе. Просто завантажена вкладка IDE запуском не є.
- Індекси — поточні позиції в порядку запуску. Запуск/зупинка можуть їх зсунути. Окремі виклики не утворюють атомарний знімок; перед наступною командою керування перечитайте список.
- Закриття Basic IDE не видаляє активних запусків. Команди стосуються цього клієнта, а не інших клієнтів чи процесів Windows.
- GetScriptsList дає індекси, GetScriptsCount — кількість, GetScriptState — код із трьох станів. Не підміняйте ці значення й не вважайте будь-яке ненульове число значенням true.
- Аргументів немає. Підрахунок не сортує список і не змінює стану запусків.

### Повна допоміжна функція

```vb
# Повна допоміжна функція
#
# Рахує активні запуски в цьому клієнті.
#
# Integer >= 0: кількість активних запусків, включно з призупиненими. Це кількість, а не Boolean
# чи індекс.

SUB Main()
    # Під Main наведено функцію повністю. Її параметри та результат пояснено окремо від API-команди,
    # яку вона викликає.
    # HasOtherScripts порівнює кількість із 1, бо скрипт зазвичай займає одну позицію сам. Ця
    # функція, на відміну від GetScriptsCount, повертає true/false.
    # Integer >= 0: кількість активних запусків, включно з призупиненими. Це кількість, а не Boolean
    # чи індекс.

    If HasOtherScripts() Then
        UO.Print("Other executions are active")
    Else
        UO.Print("No other active executions")
    End If
END SUB

Function HasOtherScripts() As Boolean
    Dim count=UO.GetScriptsCount()
    Return count > 1
End Function
```

**Пояснення параметрів і виконання:**

- Під Main наведено функцію повністю. Її параметри та результат пояснено окремо від API-команди, яку вона викликає.
- HasOtherScripts порівнює кількість із 1, бо скрипт зазвичай займає одну позицію сам. Ця функція, на відміну від GetScriptsCount, повертає true/false.
- Integer >= 0: кількість активних запусків, включно з призупиненими. Це кількість, а не Boolean чи індекс.
