# UO.GetScriptsList

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: uk -->

Повертає поточні числові індекси скриптів.

## Точний синтаксис

```text
UO.GetScriptsList() -> Array
```

## Параметри

Параметрів немає.

## Повертає

Array з Integer: індекси 0..N-1 або порожній масив. Елементи — числа, а не імена чи текстові записи.

## Поведінка

- Враховуються виконувані й призупинені запуски; завершені та ті, що отримали скасування, виключаються. Скрипт зазвичай враховує себе. Просто завантажена вкладка IDE запуском не є.
- Індекси — поточні позиції в порядку запуску. Запуск/зупинка можуть їх зсунути. Окремі виклики не утворюють атомарний знімок; перед наступною командою керування перечитайте список.
- Закриття Basic IDE не видаляє активних запусків. Команди стосуються цього клієнта, а не інших клієнтів чи процесів Windows.
- GetScriptsList дає індекси, GetScriptsCount — кількість, GetScriptState — код із трьох станів. Не підміняйте ці значення й не вважайте будь-яке ненульове число значенням true.
- Аргументів немає. Кожне число передавайте до відповідного getter імені, шляху чи стану. Масив є окремим знімком; його зміна не керує скриптами.

### Повна допоміжна функція

```vb
# Повна допоміжна функція
#
# Повертає поточні числові індекси скриптів.
#
# Array з Integer: індекси 0..N-1 або порожній масив. Елементи — числа, а не імена чи текстові
# записи.

SUB Main()
    # Під Main наведено функцію повністю. Її параметри та результат пояснено окремо від API-команди,
    # яку вона викликає.
    # FindNamedScript повертає поточний індекс першого точного збігу імені або -1. Імена можуть
    # повторюватися, а індекси — зсуватися.
    # Array з Integer: індекси 0..N-1 або порожній масив. Елементи — числа, а не імена чи текстові
    # записи.

    Dim index=FindNamedScript("Mining")
    If index>=0 Then
        UO.Print(CStr(index))
    Else
        UO.Print("Name not found")
    End If
END SUB

Function FindNamedScript(wanted) As Integer
    Dim indices=UO.GetScriptsList()
    For Each index In indices
        If UO.GetScriptName(index)=wanted Then
            Return index
        End If
    Next
    Return -1
End Function
```

**Пояснення параметрів і виконання:**

- Під Main наведено функцію повністю. Її параметри та результат пояснено окремо від API-команди, яку вона викликає.
- FindNamedScript повертає поточний індекс першого точного збігу імені або -1. Імена можуть повторюватися, а індекси — зсуватися.
- Array з Integer: індекси 0..N-1 або порожній масив. Елементи — числа, а не імена чи текстові записи.
