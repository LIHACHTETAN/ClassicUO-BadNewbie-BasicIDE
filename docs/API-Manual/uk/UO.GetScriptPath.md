# UO.GetScriptPath

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: uk -->

Читає шлях вихідного файла активного запуску.

## Точний синтаксис

```text
UO.GetScriptPath(ScriptIndex:Any) -> String
```

## Параметри

- `ScriptIndex` — Обов’язковий ScriptIndex — цілий індекс від нуля зі свіжого GetScriptsList. Від’ємний або відсутній індекс дає описаний порожній/невідомий результат. Не передавайте serial предмета, ім’я процедури чи ID запуску IDE.

## Повертає

String: збережений шлях вихідного файла або "", якщо індексу немає. Для файлового запуску це зазвичай повний шлях; команда чи код у пам’яті можуть не мати звичайного файла.

## Поведінка

- Враховуються виконувані й призупинені запуски; завершені та ті, що отримали скасування, виключаються. Скрипт зазвичай враховує себе. Просто завантажена вкладка IDE запуском не є.
- Індекси — поточні позиції в порядку запуску. Запуск/зупинка можуть їх зсунути. Окремі виклики не утворюють атомарний знімок; перед наступною командою керування перечитайте список.
- Закриття Basic IDE не видаляє активних запусків. Команди стосуються цього клієнта, а не інших клієнтів чи процесів Windows.
- GetScriptsList дає індекси, GetScriptsCount — кількість, GetScriptState — код із трьох станів. Не підміняйте ці значення й не вважайте будь-яке ненульове число значенням true.
- ScriptIndex=0 вибирає перший поточний запуск. Результат указує його вихідний файл; команда не відкриває, не зберігає й не запускає його.

Function ReadScriptPath(index, fallback) As String
    Dim path=UO.GetScriptPath(index)
    If path="" Then
        Return fallback
    End If
    Return path
End Function
