# API Manual — ClassicUO

810 имён команд; 1231 вариантов имя/число аргументов; 191 runtime-параметров.

Это внешние редактируемые файлы. Окно клиента читает файл при выборе команды. В Theia повторно откройте API Manual для обновления; файл также можно открыть в обозревателе. Кнопка Source открывает файл выбранной команды. Для изменения самой команды нужна правка исходников и сборка.

Языковые папки: en, ru, uk, fr, de, it, es, zh-tw, ja, ko. IDE и клиент выбирают язык интерфейса; сначала читают карточку из соответствующей папки, затем en, затем корневой файл. Отсутствующий перевод использует запасной файл и не считается завершённым переводом. Кнопка Source открывает именно прочитанный файл, включая его языковую папку. Редактируйте его в UTF-8; названия команд и синтаксис не переводятся.

Настройки сервера и профилей, сборка и границы проверок описаны в README_RU.md проекта. Регистр имени команды не имеет значения. Числовые serial могут быть знаковыми Integer; hex сохраняет все 32 бита. Timeout и delay обычно задаются в миллисекундах, исключения указаны в карточках.
