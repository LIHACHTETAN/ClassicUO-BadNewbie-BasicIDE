# Basic IDE release demonstrations

These seven looping GIFs were captured from the packaged Basic IDE connected to
the real client and Basic interpreter in an isolated local test fixture.
They are not mockups. Script values and API results are produced by that runtime.
No live shard, user account, personal profile or server traffic is recorded.

The recordings illustrate script controls, runtime inspection, panel placement,
theme and accent changes, command completion, and the API / Basic reference.
They are demonstrations of these UI workflows, not evidence of complete gameplay
or documentation coverage.

Each GIF is 1280 × 820 and repeats automatically. The release description links
to an immutable repository commit so its illustrations remain stable.
